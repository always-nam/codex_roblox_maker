## 스토어 설명 초안

짧은 설명:
게임 아이디어를 정리하고 다른 AI에게 전달할 제작 프롬프트를 만드세요.

자세한 설명:
게임 제작 프롬프트 메이커는 아이디어를 구체적인 제작 요청으로 준비하는 도구입니다.

게임 아이디어, 장르, 제작 인원과 경험, 목표 유저, 지원 기기, 예산과 일정, 분위기, 참고 게임, 보유 자산과 제작 범위를 입력하세요. 선택 설정을 반영한 독립적인 프롬프트를 만들어 다른 AI에게 전달할 수 있습니다.

• 인터넷 없이 입력 기반 제작 프롬프트 작성
• 군중 탐색·보물 운반·가게 경영의 서로 다른 규칙 기반 예시
• 기획·시스템·모바일·저장·보안·검증을 다루는 12개 항목

• 이 기기에 최근 결과 최대 10개 보관·삭제

이 앱은 프롬프트 준비 도구입니다. Roblox 게임을 자동으로 제작하거나 실행하지 않으며, 앱 내 AI 모델 호출을 제공하지 않습니다. 예시 기획은 실제 AI 생성 결과가 아닙니다. 만들어진 프롬프트로 게임을 제작하려면 별도 AI와 개발 도구를 이용하고 결과를 검토·테스트해야 합니다. 외부 AI 서비스의 요금은 별도입니다. 무수정 완성이나 흥행을 보장하지 않습니다.

Roblox 및 AI 제공자의 공식 서비스가 아닌 독립적인 도구입니다.

4. 개인정보처리방침 공개 URL: https://always-nam.github.io/codex_roblox_maker/privacy.html (게시 후 접속 확인 필요)
5. 문의 이메일·게시자 이름·스토어 설명·실제 앱 스크린샷·512px 아이콘·1024×500px 기능 그래픽
6. App content: 데이터 보안, 개인정보 안내, 광고 없음, 대상 연령, 콘텐츠 등급, 앱 접근 권한 질문을 실제 동작에 맞춰 답변
