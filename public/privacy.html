앱의 목적과 데이터 처리

이 앱은 사용자의 아이디어와 설정을 게임 제작용 프롬프트로 정리하는 도구입니다. 게임을 직접 제작하거나 실행하지 않습니다. 현재 Android 버전은 로그인, 광고, 결제, 분석 추적, 앱 내 AI 호출을 제공하지 않으며, 입력과 결과를 운영자 서버로 보내지 않습니다.

휴대폰에 보관되는 내용

입력 초안과 최근 결과 최대 10개를 앱의 로컬 저장소에 보관합니다. 다른 기기나 웹사이트와 동기화하지 않습니다. 보관 목록에서 개별 결과를 삭제할 수 있으며, 초안을 포함한 전체 데이터는 Android 설정의 앱 저장공간에서 데이터 삭제 또는 앱 삭제로 지울 수 있습니다. Android 자동 백업은 비활성화합니다.

복사·파일 내보내기

복사를 누르면 해당 결과를 시스템 클립보드에 기록합니다. Markdown·텍스트 내보내기는 앱의 임시 캐시에 파일을 만든 뒤 Android 공유 화면을 엽니다. 사용자가 선택한 저장 위치나 다른 앱으로 보내는 내용은 그 서비스의 정책을 따릅니다. 임시 파일은 캐시 삭제 또는 앱 삭제로 지울 수 있습니다. 공유한 외부 파일은 앱에서 자동으로 삭제하지 않습니다.

외부 AI 이용

사용자가 프롬프트를 다른 AI에 직접 붙여넣으면 해당 AI 서비스에 내용이 전달됩니다. 민감한 개인정보, 비밀번호, API 키를 아이디어나 프롬프트에 넣지 마세요. 외부 AI는 이 앱과 별도 서비스이며 요금과 개인정보 정책을 직접 확인해야 합니다.
