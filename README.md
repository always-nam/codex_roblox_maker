# 로블록스 게임 최적화 제작기 · PLAYCRAFT

한국어 반응형 웹앱입니다. 아이디어와 선택 설정을 입력하면 다른 AI에 전달할 독립적인 게임 기획·제작 프롬프트를 만들 수 있습니다. Node.js 서버가 AI 호출과 입력/결과 검증을 처리하며 API 키는 브라우저에 전달하지 않습니다.

## 현재 사용할 수 있는 기능

- 아이디어와 11가지 선택 설정, 기본 가정, 3가지 입력 예시
- **입력 기반 프롬프트**: AI 연결 없이 작성. 상세 기획이 생성되었다고 표시하지 않음
- **규칙 기반 예시 기획**: 군중 탐색·보물 운반·가게 경영에 서로 다른 루프/규칙/명세 제공. 실제 AI 생성 아님
- 일반 아이디어의 예시는 기본 시험판 구조이며 미확정 규칙을 명시함. 임의 아이디어의 맞춤 기획은 AI 연결 필요
- 11개 상세 기획 항목 + 원문을 보존한 12번째 통합 프롬프트, 목차 탐색
- 전체 복사, 클립보드 실패 시 선택 복사, UTF-8 Markdown/텍스트 다운로드
- 이 브라우저에 최대 10개 결과 보관·삭제, 입력 자동 보존. 다른 기기로 동기화하지 않음
- 빈 입력, 중복 실행 방지, 취소, 재시도, 오류 후 입력 유지
- 서버 입력/출처 검증, IP당 분당 8회 요청 제한, 기본 90초 AI 타임아웃, 연결 종료 시 제공자 요청 취소
- OpenAI Responses API 서버 어댑터와 구조화된 JSON 결과 검증

기획을 준비하는 웹앱이며 Roblox 게임 자체를 구현하거나 실행하는 서비스는 아닙니다. 무수정 완성·흥행 보장·테스트 생략을 약속하지 않습니다.

## 클라우드 실행

현재 체크아웃은 `/workspace/codex_roblox_maker`입니다. 기존 체크아웃을 사용하세요. 사용자가 요청하지 않는 한 별도 Git worktree를 만들지 않습니다.

Node.js 22 이상 필요(검증 환경: Node.js 24.19.0). **앱 실행에는 외부 npm 패키지가 필요 없습니다.**

```sh
cd /workspace/codex_roblox_maker
npm start
```

기본 포트 3000, `PORT`로 변경할 수 있습니다. 브라우저에서 열 때는 실행 플랫폼의 포트 연결 기능 또는 직접 운영하는 호스트를 사용하세요. 루프백 주소는 공개 배포 주소가 아닙니다.

내부 동작 확인:

```sh
curl --fail http://127.0.0.1:3000/api/status
curl --fail http://127.0.0.1:3000/api/generate \
  -H 'Content-Type: application/json' \
  -d '{"mode":"example","input":{"idea":"친구와 보물을 운반하고 탈출하는 게임"}}'
```

`aiConnected`는 **서버 설정 존재 여부**이며 실제 연결 성공을 뜻하지 않습니다. `connectionVerified`는 시작 시 false이며 생성 성공 여부는 각각의 요청으로 확인합니다.

## AI 연결 (선택)

현재 자격 증명이 없어 실제 AI 호출은 미검증입니다. 연결이 없어도 프롬프트와 예시를 사용할 수 있습니다.

1. 배포 플랫폼의 **서버 비밀 환경변수 설정**에 `AI_API_KEY`를 등록하세요. 키를 채팅·소스·브라우저 설정에 넣지 마세요. 로컬 서버에서는 `.env.example`을 `.env`로 복사하여 본인 서버에서만 편집할 수 있습니다. `.env`는 Git과 Docker 빌드에서 제외됩니다.
2. `AI_PROVIDER=openai`, `AI_MODEL=<사용 가능한 모델 ID>`를 설정하세요. 모델은 Responses API의 Structured Outputs를 지원해야 합니다. 앱이 모델을 임의로 선택하거나 변경하지 않습니다.
3. 서버에서 `https://api.openai.com`으로 HTTPS 요청이 가능해야 합니다. 클라우드의 프록시 비밀변수를 사용할 경우 대상 호스트와 바인딩을 설정해야 합니다. 이 앱은 예약 이름 제한을 피하기 위해 `AI_API_KEY`를 우선 사용하고, 일반 서버의 기존 `OPENAI_API_KEY`도 지원합니다. 비밀값을 브라우저에 넘기지 마세요.
4. 서버 재시작 후 ‘AI 상세 기획 생성’으로 실제 성공을 확인하세요.

`AI_TIMEOUT_MS`는 1,000~180,000ms(기본 90,000)입니다. `AI_PROVIDER=disabled`로 호출을 끌 수 있습니다. 제공자를 추가하려면 `server.mjs`의 `adapters`에 서버 함수 `(data, signal) => plan`을 등록하고 `aiConfigured()`의 설정 검사를 확장하세요. 어댑터의 출력은 항상 `validatePlan()`을 통과해야 합니다.

모델 요청에는 JSON으로 분리된 사용자 입력을 보내며, `planner.mjs`의 `systemPrompt`가 11개 항목 요구사항을 명시합니다. 서버는 11개 항목의 제목/ID/내용, 최대 3개 질문, SYS 참조 정의, Roblox Remote/Config, 테스트의 SYS 연결을 확인합니다. 12번째 프롬프트는 요약하지 않고 **검증된 기획 원문**을 그대로 포함합니다. 이 검사는 형식·참조 일관성을 검사하며, 모든 수치·경로·규칙의 의미적 모순을 자동으로 증명하지 않습니다. 결과의 적합성·정책·실제 게임 동작은 사람이 검토하고 플레이 테스트해야 합니다.

**비용:** 현재 구현/검증에서는 유료 AI 호출·호스팅 계약을 사용하지 않았습니다. 키 연결 후 생성 요청은 제공자 사용료가 발생합니다. 모델과 예상 월 요청 수가 정해지지 않아 비용을 임의로 제시하지 않습니다. 새 결제/호스팅 전에 아래 공식 가격표에서 모델별 입력·출력 토큰 단가, 평균 토큰, 월 요청 수를 확인하고 예산을 정하세요. 제공자 콘솔의 프로젝트 예산/사용량 설정도 확인하세요.

2026-10-14 공식 문서 확인: Responses API와 `text.format` JSON Schema/`strict` 구조를 확인했습니다. 실제 모델별 호출과 청구는 미검증입니다.

- API: https://developers.openai.com/api/reference/resources/responses
- 구조화 출력: https://developers.openai.com/api/docs/guides/structured-outputs
- 가격표: https://openai.com/api/pricing/
- Roblox 공식 검증 자료는 생성 프롬프트에 포함. 최신 Roblox 정책의 전체 내용은 이번 웹앱 검증에서 재검증하지 않았습니다.

## 검증

```sh
npm ci --cache /tmp/playcraft-npm-cache
npm run check
npm test
# 별도 터미널에서 npm start 실행 후, 테스트 직전 새 서버로 시작 권장
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

Playwright Core만 개발 의존성으로 고정하며 시스템 Chromium을 사용합니다. Chromium이 없는 플랫폼에서는 별도 설치가 필요합니다. `TEST_BASE_URL`로 테스트 서버 주소를 바꿀 수 있습니다. 브라우저 테스트는 새로운 브라우저 저장소에서 실행합니다. 짧은 시간에 반복하면 분당 8회 제한이 적용되므로 테스트 전 자체 서버를 재시작하거나 제한 창이 끝난 후 실행하세요.

- Node 테스트: 입력 제한·기본값·선택 설정·3개 예시 차이·12항목·기획 원문과 프롬프트 일치·누락/미정의 참조 거부·실제 HTTP 상태/출처/크기/요청 제한
- AI 테스트: 제공자 응답을 모의하여 어댑터 계약·서버 결과 검증·비밀값 비노출·실제 HTTP 타임아웃과 취소 전파 확인. 실제 AI 호출 통과를 의미하지 않음
- 브라우저: 빈 입력·선택 설정·3개 예시·복사 및 다운로드 파일 내용·클립보드 대안·미연결 오류·입력 복원·보관 열기/삭제·중복 방지·취소/재시도·모바일 가로 넘침·JS 오류
- 오류/지연 브라우저 검사는 네트워크 응답을 모의함. 실제 모바일 기기/Roblox Studio 게임 동작/실제 AI/공개 호스트는 별도 검증 필요

## 공개 배포

공개 배포는 클라우드 개발 환경과 별도입니다. 이 작업에서는 공개 주소를 만들지 않았습니다.

Node.js 지원 호스트에서 저장소를 배포하고 시작 명령 `npm start`, 포트 `PORT`, HTTPS와 비밀 환경변수를 설정합니다. 무료/유료 요금과 플랫폼 조건을 먼저 확인하세요. 런타임 의존성이 없으므로 앱 실행에 빌드 단계는 없습니다.

Docker 사용 시:

```sh
docker build -t playcraft .
docker run --rm -p 3000:3000 --env-file .env playcraft
```

키 없는 예시/프롬프트 모드에는 `--env-file`을 생략할 수 있습니다. Dockerfile은 제공했으나 현재 Docker 빌드/배포는 실행하지 않았습니다. 실제 공개 호스트에서 HTTPS·복사·다운로드·AI 요청·취소·모바일을 다시 확인하세요. 유료 AI를 로그인 없이 공개할 경우 운영 플랫폼의 사용량 제한/접근 제어가 필요합니다. 현재 제한은 단일 프로세스 메모리에 있고 재시작 시 초기화되며, 공유 IP/NAT에는 함께 적용됩니다. 프록시의 사용자 IP 헤더를 무조건 신뢰하지 않습니다. 다중 서버 운영 시 신뢰 가능한 프록시 설정과 공용 제한 저장소를 별도 구성하세요. 앱 서버는 입력/결과를 디스크에 저장하거나 요청 본문을 로그에 기록하지 않지만, AI 모드의 입력은 해당 제공자에게 전송됩니다. 호스트/제공자의 로그와 데이터 보관 정책은 운영자가 확인해야 합니다.

## 소스 구조

- `public/index.html`, `style.css`, `app.js`: 한국어 UI, 브라우저 보관, 복사/다운로드
- `planner.mjs`: 입력, 기본 가정, 예시, 시스템 프롬프트, 결과 검증, 통합 프롬프트
- `server.mjs`: 정적 파일, API, 어댑터, 타임아웃/취소/요청 제한
- `tests/`: Node/HTTP/어댑터/브라우저 검사
- `.env.example`: 비밀값 없는 서버 설정 예시

## GitHub Pages에서 테스트하기

서버 없이 사용할 수 있는 Pages 빌드도 제공합니다. 입력 기반 제작 프롬프트, 명확히 표시된 예시 기획, 복사/다운로드, 브라우저 보관을 지원합니다. 실제 AI 기획은 별도 서버가 필요하며 Pages 화면에서 키를 입력받지 않습니다.

```sh
npm run build:pages
npm run test:pages
```

`dist/`만 정적 배포합니다. 빌드는 비밀 환경변수, `.env`, 서버 파일을 포함하지 않습니다. 자산은 상대 경로이므로 `/codex_roblox_maker/` 프로젝트 경로에서 실행됩니다. 로컬 Pages 브라우저 검사 8개로 하위 경로·프롬프트·3개 예시·복사/다운로드·저장·모바일·AI 미지원 안내·API 요청 없음까지 검증합니다.

GitHub의 Pages 설정 화면에서 비공개 저장소에 ‘Upgrade or make this repository public’이 나타나면 현재 요금제에서는 활성화할 수 없습니다. 무료 공개 저장소로 전환하려면 소유자가 코드와 커밋 이력 공개를 승인해야 합니다. 비공개 유지 시 공식 GitHub 가격/요금제 조건을 확인하고 업그레이드 여부를 결정해야 합니다. 이 프로젝트가 자동으로 저장소 공개나 결제를 변경하지 않습니다.

활성화 후: Settings → Pages → Source ‘GitHub Actions’ 선택 → Actions → ‘Deploy GitHub Pages’ → ‘Run workflow’. 워크플로는 수동 실행으로 제공하며, 병합만으로 공개 배포를 시작하지 않습니다. 성공한 작업의 `github-pages` 환경에서 실제 배포 주소를 확인하세요. 예상 주소 `https://always-nam.github.io/codex_roblox_maker/`는 배포 성공과 HTTP 응답을 확인하기 전까지 검증된 링크가 아닙니다.
